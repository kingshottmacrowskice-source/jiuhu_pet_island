# 酒狐 · 云上小日子

双击「启动小岛.cmd」，在浏览器访问 http://127.0.0.1:4173 。默认首页现已使用高清材质扩建地图，包含风车、溪桥、菜园以及酒狐自主生活。旧版留在 /legacy.html。需要电脑已安装 Node.js（当前电脑已具备）。关闭命令窗口即可停止服务。

拖动旋转空岛，滚轮缩放，手机可单指旋转、双指缩放。右下角显示设备系统时间。

岛上时间独立加速循环。天气可自动变化，或选择晴、多云、雨、雪；入夜按钮切换昼夜。暂停只暂停小岛模拟，系统时钟继续运行。

酒狐参考所提供角色生成透明像素素材，以 THREE.Sprite 始终面向镜头。默认自主选择十种活动；夜间主要回床睡觉，7% 概率选择篝火打盹，雨天优先到檐廊躲雨。可点击角色或左下角箭头指定活动，恢复自在生活后继续自主行动。

选择室内活动会自动隐藏小屋外壳方便观察；「看看屋内」可手动控制。日常活动使用 16 格独立精灵表，运行时按 48×56 逻辑像素显示。行走与扫地各有两帧，除草和除虫交替，其余为独立动作姿态。床上睡觉有正面与侧面，可手动选择或随视角切换。活动菜单中的「查看全部动作精灵」提供预览与逐张下载。

源文件在 dist/，Three.js 和角色素材均在本地。字体可联网加载，失败会使用系统字体。Sites 项目已经登记，上传和部署尚未完成。
